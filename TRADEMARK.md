# The name is not the code

The code in this repository is free software and you may build whatever you
like out of it. **"Seca" is not part of that grant.**

This is the ordinary arrangement for a project that makes a promise about
privacy — Signal, Mozilla and VLC all do the same thing — and the reason is
narrow and practical. The licence makes sure a fork publishes its source. It
cannot stop a fork from being bad, and it cannot stop one from being
confused for this one. Only the name can do that.

## What is reserved

- The word **Seca**, alone or as **Seca Contacts**, **Seca Phone**,
  **Seca Messages** and **Seca Link**
- The launcher icons and the artwork in `apps/*/fastlane/.../images/`
- The application IDs `com.seca.contacts`, `com.seca.phone`,
  `com.seca.messages`, and the signing certificate they are published with

## What you may do without asking

- **Fork the code and ship it under your own name.** This is the point of
  the licence and nobody here will be unhappy about it. Change the name, the
  icon and the application ID, and you are done.
- **Say what your software is made from.** "Based on Seca", "a fork of Seca",
  "compatible with Seca" are statements of fact and welcome ones.
- **Talk about Seca.** Reviews, articles, tutorials, screenshots, packaging
  it unchanged in a repository — the name is for using when you mean this
  software.
- **Translate the name** or leave it in English, in anything you write.

## What you may not do without asking

- Publish a **changed** version of this software calling itself Seca, or a
  name close enough to be taken for it
- Use the icons or the application IDs for software that is not this one
- Suggest that your product is endorsed by, affiliated with or maintained by
  this project when it is not

## If you want to

Open an issue and ask. The answer to a straightforward request is usually
yes. The one it will not be yes to is a version that collects data from the
people using it.
